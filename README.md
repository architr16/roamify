# 🌍 Roamify – Tourism Booking Website

🔗 Live Website: https://roamify-web-nine.vercel.app/

## 📌 Project Description

Roamify is a dynamic tourism booking web application where users can explore destinations, view packages, and make bookings.

## ⚙️ Tech Stack

* Frontend: HTML, CSS, JavaScript
* Backend: Node.js, Express
* Database: MongoDB Atlas
* Deployment: Vercel
